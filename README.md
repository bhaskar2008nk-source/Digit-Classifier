# Handwritten Digit Classifier

A convolutional neural network (PyTorch) trained on MNIST, with data augmentation, learning-rate scheduling and a small Flask demo.

## Run
```bash
pip install -r requirements.txt
python train.py      # trains and saves model.pt, prints test accuracy each epoch
python app.py        # open http://127.0.0.1:5000 and upload a digit image
```
